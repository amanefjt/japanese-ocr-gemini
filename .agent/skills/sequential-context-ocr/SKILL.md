# シーケンシャル文脈 OCR (sequential-context-ocr)

## 概要
見開きやページを跨ぐ日本語の文章を、論理的な一貫性を保ったまま正確に抽出するための高度な手順。`p2workflowy` プロジェクトの知見を元に、日本語縦書きに最適化した。

## 手順 (Workflow)

### 1. 物理レイアウトの分析 (Detector)
- 画像のアスペクト比から見開き（Spread）を判定し、分割する。
- 縦書きの場合、**右ページから左ページ**の順序で処理キューを作成する。

### 2. シーケンシャル・ループ (Orchestration)
並列処理ではなく、以下の順序でループを実行する。
1. **初期状態**: `prev_text = ""`
2. **ループ開始**:
   - 現在の画像と、`prev_text` の末尾 300 文字を Extractor に渡す。
   - Extractor は、渡された文脈を元に現在の画像を OCR 抽出する。
   - 抽出されたテキストを `prev_text` に更新し、次の画像へ進む。

### 3. 文脈を考慮したプロンプト (Extraction)
- `CONTEXT_ADVISOR` テンプレートを使用し、前ページの末尾を VLM に提示する。
- VLM に対し、「前ページから継続している場合は、冒頭に見出しタグを付けない」等の具体的な制約を課す。

### 4. 物理的特徴による見出し判定 (Heuristics)
- **Moat**: 広い水平余白がある独立行を `# 見出し` とする。
- **Break**: ページの下端（縦書き）で途切れている行を判定材料にする。

## 期待される効果
- ページを跨いで単語や文章が断絶する問題を解消。
- 柱やページ番号といったノイズと、本文の誤混入を防止。
- 見出しレベルの正確な判定。
