# 操作ガイド (walkthrough.md) [v1.1-stable]

このドキュメントでは、最新の Gemini OCR ツール（CLI / Web）の使用方法と、その動作確認の結果をまとめます。

## 1. Web UI 版の使い方

ブラウザだけで完結する、最も手軽な OCR 方法です。

### 手順
1. **localhost:8000** をブラウザで開きます。
2. **APIキー設定**: Google AI Studio で取得したキーを入力し、「設定を保存」をクリック。
3. **実行ティアの選択**:
   - 無料枠の方はそのまま（2並列 / 15 RPM）。
   - 有料契約ユーザーは「有料版」に切り替えることで、20並列になり高速になります。
4. **PDF選択**: 処理したいPDFファイル（見開きでも単ページでも可）を選択。
5. **開始**: 「OCR処理を開始する」をクリック。自動的にレイアウト（見開き・二段組）が判定され、出力が始まります。

### 検証結果
- **自動判定**: 二段組書籍（見開き）を投入し、中央のノドを検知して左右分割し、さらに各ページで「上段→下段」または「全段」を自動判別して順序通りにテキスト化されることを確認。
- **並列処理**: 最大20リクエストが並列に走りつつも、最終結果はページ順に並ぶことを確認。

## 2. CLI 版 (`gemini_ocr.py`) の使い方

大量のPDFや、スクリプトによる自動化を行いたい場合に適しています。

### 基本コマンド
```bash
# 有料版ユーザー（デフォルト: 20並列高速モード）
python gemini_ocr.py Sample/hirano.pdf

# 無料枠ユーザー（3並列安全モード）
python gemini_ocr.py Sample/hirano.pdf --free
```

### 主なオプション
- `--free`: 無料枠の制限（15 RPM / 3並列）に合わせて動作します。
- `--start`: 開始ページ指定。
- `--end`: 終了ページ指定。

---

## 3. ベンチマークとコスト感 (Stable v1.1)

### 処理スピード
- **有料版 (Paid Tier)**: 見開き19ユニット分（4分割込）を約 **20秒** で完了。
- **無料枠 (Free Tier)**: レート制限待機を含め、同量を約 **2分〜3分** で完了。

### コスト (Gemini 3.1 Flash-Lite)
- **見開き 100枚（200ページ分）の文庫本**: **約 24 円**。

---

## 4. トラブルシューティング

### 429 Error (Too Many Requests)
無料枠で並列数を上げすぎると発生します。UI で「無料枠」を選択しているか、CLI で `--free` をつけているか確認してください。
