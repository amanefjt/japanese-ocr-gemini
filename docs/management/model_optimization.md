# Model Optimization Guide: Gemini 3.1 Flash シリーズ

本プロジェクトでは、2026年3月時点の最新かつ最もコストパフォーマンスに優れた **Gemini 3.1 Flash-Lite** を標準モデルとして採用します。

## ターゲット・モデル
- **標準モデル (MAIN)**: `gemini-3.1-flash-lite-preview`
- **思考レベル (THINKING_LEVEL)**: `LOW` (OCR 特化設定)

## 1. モデル選定の根拠

| モデル | RPD (無料枠) | コスト (Paid) | 採用理由 |
| :--- | :--- | :--- | :--- |
| **Gemini 3.1 Flash-Lite** | **500 RPD** | **極低価格** | 圧倒的なクォータ（500回/日）と低コスト。OCR精度も十分。 |
| **Gemini 3.1 Flash** | 20 RPD | 中コスト | 非常に複雑なレイアウトや手書き文字などの難易度が高い場合に使用。 |
| **Gemini 1.5 シリーズ** | 制限あり | - | **【廃止 / 役割終了】** 推論能力・コストの両面で 3.1 に劣る。 |

## 2. OCR 特化設定: Thinking Level "LOW"

日本語書籍の活字 OCR においては、最新の `thinking_level` パラメータをあえて **`LOW`** に設定することを推奨します。

- **理由**: 特定の活字ページで `HIGH` を使用すると、AIが「過剰思考（Overthinking）」に陥り、TTFT（最初の1文字が出るまでの時間）が170秒を超えるスパイクが発生することが技術監査で判明。
- **効果**: `LOW` を採用することで、精度を維持したままTTFTが平均約9秒→5秒へと高速化され、処理の安定性が劇的に向上します。

## 3. 最新の価格体系 (Paid Tier)

Gemini 3.1 シリーズの価格（プレビュー版、100万トークンあたり）は以下の通り、以前よりも大幅に引き下げられています。

| 項目 | **Gemini 3.1 Flash-Lite** | Gemini 3.1 Flash |
| :--- | :--- | :--- |
| **入力 (テキスト/画像)** | **$0.075** (約 11 円) | $0.50 (約 75 円) |
| **出力 (テキスト)** | **$1.50** (約 225 円) | $3.00 (約 450 円) |

*※ $1 = 150円換算。*

### コスト試算: 文庫本1冊 (100見開き / 200ページ)
- **総入力トークン**: 約 260,000 tokens ($0.0195)
- **総出力トークン**: 約 64,000 tokens ($0.096)
- **合計コスト**: **約 17.3 円** ($0.1155)

文庫本1冊を丸ごと V3 パイプライン（文脈提示あり）でデータ化しても、**わずか20円以下** という圧倒的な低コストで運用可能です。

## 4. レート制限と並列実行

- **有料版 (Paid)**: 20並列 / 500 RPM (標準)。高速性を優先。
- **無料版 (Free)**: 3並列 / 15 RPM (安全)。安定性を優先。
- **自動調整**: `OCROrchestrator` は指定されたティアに応じてこれらの制限を自動的に適用します。
