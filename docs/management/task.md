# タスク: Gemini OCR リファクタリング

## 目的
`gemini_ocr.py` を商用レベルの堅牢なコードにリファクタリングし、メモリ効率の改善（OOM対策）と読字順序を制御する高度なプロンプトを導入します。

## DoD (完了の定義)
- [ ] 関数分割による単一責任原則の遵守（SOLID）。
- [ ] ジェネレータによるメモリ効率の高い画像抽出の実装（OOM対策）。
- [ ] 指数的バックオフを含む頑健なリトライロジックの実装。
- [ ] RTL（右から左）の読字順序を制御する新プロンプトの適用。
- [ ] ローカル環境での動作検証と履歴（Walkthrough）の作成。
