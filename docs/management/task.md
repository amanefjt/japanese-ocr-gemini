# タスク: Gemini OCR 高速化・自動化プロジェクト [COMPLETED v1.1]

## 目的
Gemini API (3.1/3.0) の特性を最大限に活かし、学術・文本文献のOCR処理を「高速」かつ「全自動」で、さらに「低コスト」で運用するための環境構築。

## DoD (完了の定義)
- [x] **並列処理エンジンの実装**: 順序保証付きの並列実行により、処理時間を 1/3 以下に短縮。
- [x] **マルチティア対応**: 無料枠（15 RPM）と有料枠（2000 RPM）の動的な切り替え。
- [x] **全自動レイアウト判定**: 一段組・二段組（見開き）を画像解析で自動判別し、適切に画像を分割してOCR実行。
- [x] **Web UI 刷新**: デザインのシンプル化、モデル選択の排除、直感的な操作感の実現。
- [x] **インフラ・コスト知見の集約**: `thinking_level: LOW` による TTFT 短縮と、1ページ 0.1円単位の低コスト運用の実証。
