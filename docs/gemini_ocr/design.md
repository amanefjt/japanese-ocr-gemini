# Web版 OCR ロジックの改善とオプション追加

Python版 (`gemini_ocr.py`) での実装成果を Web版 (`index.html`) にも反映し、機能の同期と堅牢性の向上を図ります。

## 変更内容の概要

### 1. UIの更新 (`index.html`)
- 「実行設定」セクションに以下のオプションを追加します。
    - **見開き解析の強制指定**:
        - `自動判定 (標準)`
        - `単一ページとして強制 (`--single` 相当)`
        - `見開きとして強制 (`--spread` 相当)`
- ユーザーに現在の設定が伝わりやすいよう説明文を微調整します。

### 2. 解析ロジックの改善 (`index.html` JavaScript)
- **アスペクト比閾値の変更**: 見開き判定の閾値を `1.2` から `1.1` に変更します。
- **安全性優先 (Safety First) の強化**: 
    - ノド（綴じ目）の検出精度（信頼性）が低い場合、無理に分割せず単体ページとして処理するロジックを Python版と同期させます。
    - 強制見開きモード (`--spread`) 時でも、ノドが全く見つからない場合は安全のために分割をスキップするガードを設けます。

### 3. プロンプトの共通化
- Python版の知見に基づき、読み取り順序やノイズ除去の指示を最新化します。

## 影響範囲
- `index.html` のみ。

## 検証計画
- `ethnopdf.pdf` を Web版で開き、以下の動作を確認します。
    - 自動判定で「単体ページ」として処理され、文字が断裁されないこと。
    - オプションで「単一ページ強制」が正しく機能すること。
    - 「見開き強制」を選択しても、ノドが不鮮明な場合に安全にスキップ（または最適な分割）が行われること。
