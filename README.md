# 日本語見開き縦書きPDFのOCR (Gemini API版)

Google Gemini APIを使用して、日本語の縦書き・見開きPDFを高精度にテキスト化するツールです。
国立国会図書館デジタルコレクションや「自炊」書籍のスキャンデータ（見開き2ページ、縦書き、2段組など）の文字起こしに最適化されています。

## 特徴

*   **完全ローカル & Python CLI 両対応**: 
    -   **Web版**: `index.html` をブラウザで開くだけで動作。サーバー不要。
    -   **CLI版 (V3)**: `gemini_ocr_v2.py` による高度な文脈維持抽出。
*   **シーケンシャル文脈 OCR (New)**: 前ページの末尾を文脈として次ページに渡すことで、文章の結合精度が劇的に向上。
*   **Gemini 3.1 Flash-Lite / Pro 最適化**: 高精度・高速・格安な最新構成。
*   **レイアウト全自動判定**: 見開き分割、一段組/二段組の判定を画像解析で自動実行。
*   **物理レイアウト判定 (Moat & Break)**: 余白や行末の断絶を検知し、正確な見出し抽出を実現。
*   **高度な並列処理**: 有料版ユーザーなら20並列同時実行が可能。

## 使い方 (Web UI版)

1.  **起動**: `index.html` をブラウザ（Chrome推奨）で開きます。
2.  **設定**: APIキーを入力し「設定を保存する」を押します。
3.  **ティア選択**: 
    *   **無料枠**: 2並列 / 15 RPM 制限。安全に動作します。
    *   **有料版**: 20並列 / 2000 RPM 制限。圧倒的な速度で処理します。
4.  **実行**: PDFファイルを選択し、ページ範囲を指定して「OCR処理を開始する」を押します。

## 使い方 (CLI版)

Python 3.9+ が必要です。

1.  **準備**:
    ```bash
    pip install -r requirements.txt  # numpy, pillow, pdf2image, google-genai, aiolimiter, python-dotenv 等
    ```
2.  **.env 設定**:
    `GEMINI_API_KEY=あなたのキー` を記述した `.env` ファイルを作成。
3.  **実行**:
    ```bash
    # 標準設定 (V3 パイプライン)
    python gemini_ocr_v2.py path/to/your.pdf
    ```
4.  **オプション**:
    - `--free`: 無料枠ユーザー（15 RPM / 3並列）制限を遵守。
    - `--single`, `--spread`, `--start`, `--end`: ページ構成の強制や範囲指定。

## ベンチマークとコスト

*   **処理スピード**: 100見開き（200ページ）を無料枠で約15分、有料版で約2分で完了。
*   **コスト**: 1Mトークンあたり $0.25 (Input) / $1.50 (Output) という Flash-Lite の破格の安さを活かし、文庫本一冊を数十円レベルでデータ化可能です。
